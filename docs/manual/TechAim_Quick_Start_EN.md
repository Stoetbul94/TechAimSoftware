## 1. Welcome to Tech Aim

Tech Aim is electronic target scoring and training software for ISSF shooting
disciplines. It records each shot, scores it, and gives athletes and coaches
measured feedback — both for competition-style sessions and for structured
training exercises in the **Training Lab**.

This guide gets you through one complete session. The full reference is
`TechAim_Operator_Manual_EN.md`.

## 2. Safety and scope

- **Range safety rules always take precedence over this software.** Tech Aim
  displays range commands; it does not control the range.
- This is a **Pre-Beta Validation** build. It is not certified software, and
  it is not ISSF-certified or SETA-certified.
- **Demo mode results are not physical results.** They are generated by the
  software with no target attached, and must never be presented as an
  official or physical outcome.
- Training Lab reports state *"Not an official competition result"*. That
  wording is deliberate — do not remove it when sharing reports.

## 4. Starting Tech Aim

1. Run **`TechAim.exe`**.
2. The window title reads **Tech Aim Electronic Target Control**.

**Expected result:** the home screen appears.

**Common mistake:** launching an old `Seta.exe`. The product is now
`TechAim.exe`; a build that still shows *Seta* is outdated. Only one instance
can run at a time — a second launch shows **"Tech Aim is already running."**

[HUMAN VISUAL CHECK REQUIRED] — window caption and taskbar text.

## 5. Selecting English or German

1. Open **Settings**.
2. Under **LANGUAGE**, choose **English** or **Deutsch (Beta)**.

**Expected result:** the interface switches language. If a **Restart
required** note appears, restart to finish applying it.

> **German is a beta translation.** Roughly 100 of 583 translatable strings
> are translated; everything else deliberately stays in English, so a German
> session is currently **mixed-language**. See
> `TechAim_German_Translation_Status.md`.

## 6. Live and Demo mode

| Mode | Shot source | Use it for |
|---|---|---|
| **Live target** | The physical electronic target | Real shooting |
| **Demo / simulation** | Software-generated shots | Training on the software, demonstrations, testing |

The mode is shown in **Settings ▸ OPERATING MODE** as **Current mode:**.

Tech Aim enforces the mode: in Live it rejects simulated input, and in Demo it
rejects physical-target input. This is deliberate — it stops a demonstration
from being mistaken for a real result.

Changing mode uses **Restart Now** or **Restart Later**.

## 8. Selecting an athlete

Select or enter the athlete on the home screen before starting.

**Why it matters:** the athlete name is written into the session record and
printed on every exported report.

[HUMAN VISUAL CHECK REQUIRED]

## 9. Selecting a discipline

Choose the discipline. Currently supported:

- 10 m Air Rifle
- 10 m Air Pistol
- 50 m Rifle Prone
- 50 m Rifle Three Positions

**Note:** discipline choice controls what else is offered. **Position
Transition** appears in the Training Lab **only** when 50 m Rifle Three
Positions is selected.

## 10. Selecting an event or Training programme

Either a competition/practice event, or a **Training Lab** programme:

| Programme | Available for |
|---|---|
| Technical Blocks | supported disciplines |
| Call & Diagnose | supported disciplines |
| Position Transition | **50 m Rifle Three Positions only** |

Group Pattern analysis is **not** a separate programme — it is an analysis
layer that appears inside the others as **GROUP PATTERN INSIGHTS**.

## 11. Starting a session

Start the session from the setup screen. The shooting screen opens.

## 12. Understanding the shooting screen

| Region | Shows |
|---|---|
| Centre | The target face and your shots |
| Right panel | Session status and the primary action button |
| Header | Athlete, discipline, connection |

In **Training Lab** modes the right panel is programme-specific and headed
**TRAINING LAB** with the programme name beneath it.

**Competition overlays are deliberately hidden during Training Lab sessions.**
You should **not** see a match countdown clock or the red `000` shot counter.
If you do, that is a defect — report it.

## 13. Sighters and counted shots

- **Sighters** are practice shots. They are **never** included in counted
  results or group metrics.
- **Counted shots** are recorded and scored.

Training programmes show progress as **Shot 0 of N**, counting only counted
shots.

## 14. Ending the session

Let the session run to completion, or use the programme's end action
(for example **End Training**).

## 15. Viewing results

The completion summary appears in the main view. Training Lab summaries
include measured metrics, a group plot, **GROUP PATTERN INSIGHTS** where
there is enough data, and observations.

**Important:** Tech Aim reports *measured patterns and timing*. It does
**not** prove the technical cause of them.

## 16. Exporting a PDF

1. Select **EXPORT PDF** on the summary.
2. Choose or confirm the destination.

**Expected result:** a branded Tech Aim PDF is written.

**If it fails:** see *PDF will not export* in
`TechAim_Troubleshooting_EN.md`.

[HUMAN VISUAL CHECK REQUIRED] — destination dialog and default folder.

## 17. Returning Home correctly

Use **Home** on the summary.

**Expected result:** the session closes cleanly and no stale session state
remains. Reopening must not suggest you are still in the previous session.

**Common mistake:** killing the application instead of using **Home**. That
leaves the session unfinished and it will be offered for recovery next time.

## 18. Recovering an interrupted session

Tech Aim records progress as it happens, so an interrupted session can
normally be resumed safely.

After a crash or power failure, a recovery dialog offers the unfinished
session — **Resume Match** / **Resume Training**, or **Discard**.

A **cleanly completed** session must **never** be offered as unfinished.

## 19. Five common problems

| Problem | First thing to check |
|---|---|
| No shot received | Are you in Live mode with the target connected, and in a phase that accepts shots? |
| A shot was ignored | Shots fired during **Position Setup** are deliberately ignored. |
| Sighters appear in results | They should not. Sighters are excluded by design — report it. |
| PDF will not export | Is the destination writable, and is the file already open? |
| Wrong or missing German text | Untranslated text stays in English by design. |

Full fault-finding: `TechAim_Troubleshooting_EN.md`.

## 20. Contacting support

Send:

1. **Version and build** — Settings ▸ **ABOUT / BUILD** (version, **Commit:**,
   **Built:**).
2. **Operating mode** — Live or Demo.
3. **Discipline and programme**.
4. **What you did, what you expected, what happened.**
5. **The exported PDF** if the problem concerns a report.

Do **not** send athlete personal data that is not needed.
