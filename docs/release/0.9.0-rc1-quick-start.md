# Tech Aim 0.9.0-RC1 — field quick start

**FIELD TEST — NOT FOR OFFICIAL COMPETITION RESULTS**

One page. Print it and take it with you.

---

## BEFORE LEAVING

- [ ] RC1 package copied to the test laptop
- [ ] Rollback package copied to the test laptop
- [ ] **Both** copied to a second USB drive where available
- [ ] Laptop charger packed
- [ ] Target power supply confirmed
- [ ] Target communication cable confirmed (and a spare if you have one)
- [ ] Administrator access on the laptop confirmed, if the range needs it
- [ ] **Windows sleep set to Never** for the duration of testing
- [ ] Laptop date and time correct
- [ ] Adequate free disk space (allow 2 GB)
- [ ] Printed field-test checklist and physical shot log

---

## AT THE RANGE

1. **Extract RC1 into a new folder.**
2. **Do not run it from inside the ZIP.** Windows will appear to work and then
   fail in ways that waste your morning.
3. Start `TechAim.exe`.
4. Confirm version **0.9.0-RC1**  *(Settings → ABOUT / BUILD)*
5. Confirm channel **Internal Field Test**
6. Confirm operating mode **Live**
7. Record target details on the checklist — model, board, firmware, serial,
   connection, COM port, distance, discipline.
8. **Connection-only test** — Stage A. No projectile.
9. **One-sighter test** — Stage B.
10. **One-counted-shot test** — Stage B.
11. **Continue only if both appeared exactly once**, with the right score and
    coordinates.

If either appears twice, or not at all, or with the wrong values — that is
**Severity 1**. Stop.

---

## AFTER A FAILURE

1. **Stop firing.**
2. **Photograph the screen** — before touching anything.
3. **Record the time** on the checklist.
4. **Do not delete the session.** It is the evidence.
5. **Create a support bundle:**
   ```bash
   powershell -File Make-SupportBundle.ps1 -SessionId <session id>
   ```
6. Preserve the target state where it is safe to do so.
7. Classify: Severity 1 (blocking) / 2 (major, workaround exists) / 3 (cosmetic).
8. Roll back if required — `0.9.0-rc1-rollback.md`. **Preserve evidence first.**

## The two packages — do not confuse them

| | Version shown | Channel shown |
|---|---|---|
| **RC1 — the one under test** | `0.9.0-RC1` | Internal Field Test |
| **Rollback — the fallback** | `0.9.0` | Pre-Beta Validation |

Check the banner under **Settings → ABOUT / BUILD** before you trust which one
is running.

---

## Never

- Never interrupt target power while a projectile is being fired.
- Never continue after a Severity 1 failure "to gather more data" unless the
  range is in a controlled diagnosis state with no athlete relying on results.
- Never treat an RC1 result as an official competition result.
