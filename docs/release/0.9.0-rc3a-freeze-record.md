## Root cause of the RC3 launch failure

A QML **syntax** error in `LoginPage.qml`, introduced in `69b84a1` when the
legacy Tachus background reference was removed: the explanatory comment was
placed *inside* a single-line element, so `//` swallowed the rest of the line
including its closing brace. `engine.load("qrc:/main.qml")` then returned no
root objects and `main()` returned **-1** — the process started, loaded every
plugin cleanly and exited before showing a window.

**It was not a deployment fault.** `release\TechAim.exe` was equally broken.
`rcc` embeds QML as bytes without parsing it, the compiler never sees QML, and
no suite loaded `LoginPage.qml` — so the Release build, every C++ harness and
the QML suite were all green against a binary that could not start.

**QML-PARSE-001** closes that hole: every root `.qml` is parsed through the QML
engine and parse-level errors fail the suite. Type and context errors are
ignored, since these files are not instantiated with the application context.

## Windows icon

The generic icon was correct behaviour — `TechAim.rc` carried no `ICON`
resource. `images/logo/techaim.ico` is the target emblem cropped from the
approved `images/logo/techaim_color.png`, at all seven Windows sizes
(16/24/32/48/64/128/256). No new logo was drawn; the wordmark was rejected at
3.25:1 as illegible below ~64 px. It is the first `ICON` resource in the
executable, and the installer assigns it explicitly to both shortcuts.

Verified: `ExtractAssociatedIcon` on the staged `TechAim.exe` returns the
emblem, not a generic icon.

**The installed copy has NOT been verified**, because installing requires
elevation this session does not have. That step remains Arnold's:

1. Run `dist\rc3\TechAim-0.9.0-RC3a-SETA-Evaluation-Setup.exe` as administrator
   and accept the default `C:\Program Files\Tech Aim`. **RC3 was installed to
   `C:\Users\User\Desktop\Tech Aim`** — if that install is still present,
   uninstall it first so the two do not confuse each other.
2. Launch from the Start Menu shortcut, then the Desktop shortcut.
3. Confirm both shortcuts show the Tech Aim target emblem, not a generic icon.
4. Confirm About/Build reads 0.9.0-RC3a-SETA / SETA Evaluation.
5. Close, relaunch, uninstall.
