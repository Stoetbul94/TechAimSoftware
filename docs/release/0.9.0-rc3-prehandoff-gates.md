## 2. Local install check — steps for Arnold

UAC is not bypassed; this needs an interactive elevated run.

1. Right-click `dist\rc3\TechAim-0.9.0-RC3-SETA-Evaluation-Setup.exe` →
   **Run as administrator**.
2. Accept the default location `C:\Program Files\Tech Aim`.
3. Launch from the **Start Menu** shortcut
   "Tech Aim 0.9.0-RC3 (SETA Evaluation)".
4. Prove the running process is the installed copy, not the repo build — in
   PowerShell: `Get-Process TechAim | Select-Object Path` must read
   `C:\Program Files\Tech Aim\TechAim.exe`, never the repository `release`
   folder.
5. Settings → **About / Build**: version `0.9.0-RC3-SETA`, channel
   **SETA Evaluation**.
6. Confirm the notice
   **"Evaluation Build — Not for Official Competition Results"**.
7. Inspect Home · 10 m Air Rifle · 10 m Air Pistol · 50 m Prone · 50 m 3P ·
   Training Lab · Settings · English ↔ Deutsch, per
   `0.9.0-rc3-seta-manual-check.md`.
8. Close the application.
9. Relaunch from the shortcut — must start clean: no unfinished match, no
   remembered target.
10. Uninstall via Settings → Apps, or the Start Menu uninstall entry.

No live firing.
