## Option A — second Windows computer (preferred)

Prefer a machine with **no Qt development tools**. A range laptop, an office
machine, anything that was never used to build Tech Aim.

1. Copy the ZIP across (USB or network).
2. Verify the SHA-256 as above.
3. Extract to a **new empty folder** — for example `C:\TechAimTest\RC1`.
   Do not run from inside the ZIP.
4. Do not add the repository or any Qt directory to `PATH`.
5. Continue at **The sequence** below.

## Option B — Windows Sandbox

**Only if Windows Sandbox is already installed and enabled.** Do not enable it
for this test.

Check: Start → type "Windows Sandbox". If it is not there, use Option A.

1. Start Windows Sandbox.
2. Copy the ZIP into the sandbox (drag and drop, or a shared folder).
3. Extract inside the sandbox.
4. Continue at **The sequence**.

Sandbox limits worth knowing: everything is discarded on close, so **capture
screenshots and copy any logs out before closing**; and a sandbox has no serial
port, so it can validate startup but never target communication.
