## Latency — corrected diagnosis

**An earlier statement in this session was wrong and is corrected here.** The
delay was attributed to a 1000 ms poll interval. That is not the shot path.

Measured on the third counted shot:

| From | To | Elapsed |
|---|---|---|
| target count observed `17:33:54.108` | `decoded` `.190` | 82 ms |
| | marker **visible** `.296` | **188 ms** |
| | zoom started `.311` | 203 ms |
| | motor feed complete | 1655 ms |

The UI, scoring and rendering path is **not** responsible for a half-second to
one-second perceived delay. See
[0.9.0-polling-architecture.md](0.9.0-polling-architecture.md) for what is.
