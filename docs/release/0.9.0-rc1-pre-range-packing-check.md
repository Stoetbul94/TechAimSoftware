## Two rules for the folder layout

1. **Never extract RC1 and the rollback into the same folder.** Use
   `C:\TechAimTest\RC1\` and `C:\TechAimTest\Rollback\`.
2. **Never run either from inside the ZIP.**

Confirm which build is running from **Settings → ABOUT / BUILD**:

| Build | Version | Channel |
|---|---|---|
| RC1 — under test | `0.9.0-RC1` | Internal Field Test |
| Rollback — fallback | `0.9.0` | Pre-Beta Validation |

- [ ] Both extracted to **separate** folders
- [ ] Both checksums verified on the test laptop

      *(it reads the manifest and the executable from its own directory)*
