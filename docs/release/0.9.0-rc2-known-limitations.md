## 3. Training Lab evidence status

**No Training Lab threshold has been reviewed by a coach.** Every one is a
**REASONED PRODUCT RULE — COACH REVIEW REQUIRED**.

Nothing in this build may be described as:

- scientifically proven
- coach approved
- an official ISSF diagnostic rule

Training observations **describe recorded patterns and do not replace qualified
coaching judgement.** Impact data alone cannot determine the technical cause of
a shot — the variables that dominate shooting score are measured by aim-trace
instrumentation, which Tech Aim does not have.

Full position: `docs/research/training-lab-evidence-register.md`.
Open coach questions: `docs/research/training-lab-coach-review-pack.md`.

## 4. Analytics version

Wind Map analyses are stamped **`windmap-analytics-v2`**, which classifies
dispersion by radial RMS. An analysis produced by an earlier build used extreme
spread and is **not** comparable. The version is shown in the analysis session
block and under **Settings → ABOUT / BUILD**.

## 5. Known deferred items

- Generated operator manuals carry a stale commit stamp (documented
  **181 / 14** deferred result). Manual regeneration happens after acceptance.
- `GroupPatternAnalyzer` drift and expansion are computed on thirds and halves,
  so at the 5-shot minimum a "third" is one shot. Raising the minimum is in the
  coach review pack.
- Position Transition first-shot-in-group is **FUTURE VALIDATION REQUIRED** —
  displayed as a measurement, and it drives no conclusion.

## 6. Reporting a problem

Run `Make-SupportBundle.ps1` from the application folder. Add `-SessionId
<id>` to include one session's journal; without it no session data is
collected. Check the bundle before sending it on.

Severity 1 (release blocking): wrong score · lost shot · duplicated shot ·
corrupted journal · recovery failure · target will not connect · repeated
crash in normal operation · one athlete's data in another session · a
completed session reopening as active · package will not launch.
