## Status

### SOFTWARE PACKAGE READY — YES

Release build succeeds · deployment audit passes · ZIP created · SHA-256
recorded · local portable launch passes · **no Severity 1 software defect is
open**.

### Weekend field test — BLOCKED — PHYSICAL TEST REQUIRED

The gate requires clean-machine launch, physical target connection, at least
one sighter captured once, at least one counted shot captured once, no
duplicate or lost shot, forced-termination recovery, reconnect, and a ready
rollback package.

**None of the eight has been satisfied.** The rollback PROCEDURE is written,
but the rollback BINARY is not preserved: the slot at `dist/previous/` holds
only instructions, because the only built binary available was RC1 itself and
shipping that as its own rollback target would be worse than shipping nothing.
The rest require hardware and a second machine. None is converted into a pass.

   work through the 15-step sequence in `0.9.0-rc1-test-results.md` §5.
