===============================================================================
 TECH AIM RMS - FIELD-TEST CHECKLIST
 Milestone 4.5 - target display MVP
 FIELD TEST / DEVELOPMENT EVALUATION - not a competition release
===============================================================================

 This checklist is for a PERSON to work through. Nothing on it has been ticked
 by the developer, and none of it should be reported as passing until you have
 actually done it. Automated tests and screenshots cannot prove that a button
 is wired to the thing it says it does; only clicking it can.

 Tester: ______________________     Date: ______________

 Machine / screen size: _______________________________________________

 Work down the list. If something fails, write what you saw next to it - what
 you expected matters less than what actually happened.


-------------------------------------------------------------------------------
 A. IT STARTS
-------------------------------------------------------------------------------

 [ ] The application launches by double-clicking Launch-TechAimRMS-Demo.cmd
 [ ] No error about a missing DLL, plugin or "Qt platform plugin"
 [ ] The header says DEMO RANGE - NOT REAL TARGETS
 [ ] The header also says NOT OBSERVING - UDP 7755
 [ ] The demo range loads: six lanes appear within about ten seconds


-------------------------------------------------------------------------------
 B. THE PAGES
-------------------------------------------------------------------------------

 [ ] HOME opens and shows something sensible
 [ ] LIVE RANGE opens and lists the six lanes
 [ ] LIVE RANGE - clicking a lane opens its detail
 [ ] NEW MATCH opens and shows the seeded plan
 [ ] ATHLETES opens and lists the six demo athletes
 [ ] RANGE SETUP opens and shows the demo range and its lane assignments
 [ ] DISPLAYS opens


-------------------------------------------------------------------------------
 C. DISPLAYS - ALL TARGETS
-------------------------------------------------------------------------------

 [ ] ALL TARGETS shows six target faces with shots on them
 [ ] The faces look like real ISSF targets, not generic circles
 [ ] Clicking Lane 1's tile opens Lane 1 large
 [ ] The lane strip under the toolbar highlights the lane you are on


-------------------------------------------------------------------------------
 D. DISPLAYS - NAVIGATION
-------------------------------------------------------------------------------

 [ ] PREVIOUS moves to the previous lane
 [ ] NEXT moves to the next lane
 [ ] PREVIOUS from Lane 1 wraps round to Lane 6
 [ ] NEXT from Lane 6 wraps round to Lane 1
 [ ] Clicking a lane in the strip jumps straight to it
 [ ] ALL TARGETS returns to the overview
 [ ] MATCH LANES / ALL LANES changes which lanes are walked


-------------------------------------------------------------------------------
 E. DISPLAYS - FULL SCREEN
-------------------------------------------------------------------------------

 [ ] FULL SCREEN fills the whole screen
 [ ] The target is readable from across a room
 [ ] PREVIOUS / NEXT work in full screen
 [ ] The LEFT and RIGHT arrow keys work in full screen
 [ ] ALL TARGETS in full screen shows the whole range, filling the screen
 [ ] The EXIT FULL SCREEN button leaves full screen
 [ ] ESC leaves full screen
 [ ] If you have a second monitor: the DISPLAY OUTPUT picker moves the window


-------------------------------------------------------------------------------
 F. DISPLAYS - AUTO ROTATE
-------------------------------------------------------------------------------

 [ ] AUTO ROTATE starts cycling through the lanes
 [ ] The button changes to STOP ROTATE while it is rotating
 [ ] Changing the interval (5s / 10s / 15s / 30s) changes the speed
 [ ] Pressing NEXT, PREVIOUS or clicking a lane STOPS the rotation
 [ ] STOP ROTATE stops it
 [ ] SPACE starts and stops rotation in full screen


-------------------------------------------------------------------------------
 G. THE STATES WORTH LOOKING AT
     (leave the demo running for about a minute first)
-------------------------------------------------------------------------------

 [ ] Lane 3 goes OFFLINE and STAYS in the list - it is dimmed, not removed
 [ ] Lane 3 still shows its last known shots and score while offline
 [ ] Lane 4 goes offline and comes back
 [ ] Lane 4 then shows an unseen-shot warning
 [ ] Opening Lane 4 large explains it: how many shots are drawn, how many the
     station accepted, and both totals
 [ ] The big TOTAL is the station's total, not RMS's own sum
 [ ] Lane 5 shows FINISHED
 [ ] Lane 6 shows ELIMINATED, in a different colour from FINISHED
 [ ] BOTH of those are clearly marked SIMULATED
 [ ] An eliminated lane is NOT dimmed like an offline one


-------------------------------------------------------------------------------
 H. RESTART AND RESET
-------------------------------------------------------------------------------

 [ ] Close RMS and launch the demo again - the range is still configured
 [ ] Reset-Demo.cmd restores the demonstration to the beginning
 [ ] After a reset the range rebuilds itself and starts shooting again


-------------------------------------------------------------------------------
 I. LIVE MODE, AND THAT THE DEMO DID NOT DAMAGE IT
-------------------------------------------------------------------------------

 [ ] Launch-TechAimRMS-Live.cmd starts
 [ ] The header says LIVE, and OBSERVING UDP 7755
 [ ] It does NOT show the demo range, the demo athletes or the demo plan
 [ ] With no stations broadcasting, it correctly shows nothing found
 [ ] If you had a real range configured before, it is still there
 [ ] Going back to the demo does not disturb the live configuration


-------------------------------------------------------------------------------
 J. THE THING THAT MATTERS MOST
-------------------------------------------------------------------------------

 [ ] There is NO button anywhere that starts, stops, resets, loads, pauses or
     resumes anything on a target
 [ ] Nothing on any page offers to change what a station is doing
 [ ] Closing RMS has no effect on anything else

 If you find a control that appears to command a target, stop and report it.
 That would be a defect of the most serious kind in this product.


-------------------------------------------------------------------------------
 NOTES
-------------------------------------------------------------------------------

 In DEMO mode the position a shot is drawn at does not match the score printed
 beside it. That is expected: the demonstration invents positions and scores
 separately, on purpose. Judge the LAYOUT and the BEHAVIOUR here, not the
 arithmetic.

 The display has never been checked against a real target. When real hardware
 is available, the first thing to verify is that a shot drawn on the screen is
 where the pellet actually went.
